# Origins Cocoa

Premium Indian cacao brand website — farm to fermentery to makers.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Typography (Ivy Presto)

This site uses **Ivy Presto**, a commercial typeface (not available on Google Fonts). Add your licensed font files to `public/fonts/`:

| File | Weight | Usage |
|------|--------|-------|
| `IvyPresto-Regular.woff2` | 400 | Body text, links |
| `IvyPresto-Medium.woff2` | 500 | H2 headings |
| `IvyPrestoDisplay-Light.woff2` | 300 | H1 headings |
| `IvyPrestoDisplay-Medium.woff2` | 500 | H3 headings |
| `IvyPrestoDisplay-Regular.woff2` | 400 | Paragraphs |

Until the files are added, the site falls back to Cormorant Garamond, Playfair Display, and Georgia.
